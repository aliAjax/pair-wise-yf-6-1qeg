# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版闭环（预算批次）：

- 创建批次时勾选未完成且未纳入批次的事项并填写总预算；合计预计费用超过预算则整批拒绝，事项状态与批次均不变化。
- 批次开工后，批次内事项统一进入处理中，必须确认实际费用才能完工；批次实际费用合计超过预算时必须填写并保留超支原因，全部事项完工后批次自动闭环。
- 取消批次只释放未开工事项（待开工批次释放全部待处理事项，进行中批次释放剩余待处理事项）；已开工/已完工事项继续保留并可继续完工。
- 批次列表与事项列表、三项统计（未完成 / 处理中 / 预计费用）联动，全部数据通过 localStorage 持久化，刷新后恢复。
